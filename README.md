# Dealership Application

A desktop dealership interface built using JavaFX and FXML with Scene Builder. The application allows users to browse and filter inventory across multiple vehicle categories, view specifications, and simulate purchasing or financing options.

---

## Features

- **Vehicle Categories:** Browse inventories for SUVs, Sedans, Sports Cars, and Trucks.
- **Specification Viewer:** Inspect vehicle details including make, model, year, horsepower, and pricing.
- **Interactive UI:** Clean graphical interface designed with Scene Builder and styled using CSS.


---

## Tech Stack

- **Language:** Java
- **UI Framework:** JavaFX
- **Layout & Design:** FXML, Scene Builder
- **Build Tool:** Maven
